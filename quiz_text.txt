

Q1. What is data independence?
A. Ability to store data without a database
B. Ability to change one schema level without significantly affecting higher levels
C. Ability to delete database records
D. Ability to access a database without SQL
Answer: B
Q2. How many major types of data independence are there?
A. One
B. Two
C. Three
D. Four
Answer: B
Q3. The two types of data independence are:
A. External and internal
B. Logical and physical
C. Structural and functional
D. Static and dynamic
Answer: B
Q4. Which architecture is closely associated with data independence?
A. Two-tier architecture
B. Three-schema architecture
C. Client-server architecture
D. Peer-to-peer architecture
Answer: B
Q5. The three levels of the ANSI/SPARC architecture are:
A. User, Application, Database
B. External, Conceptual, Internal
C. Physical, Logical, Network
D. Input, Processing, Output
Answer: B
Q6. Which schema represents individual user views?
A. Internal schema
B. Conceptual schema
C. External schema
D. Physical schema
Answer: C
Q7. Which schema describes the overall logical structure of the database?
A. External
B. Conceptual
C. Internal
D. Storage
Answer: B
Q8. Which schema describes how data is physically stored?
A. External
B. Conceptual
C. Internal
D. User
Answer: C
Q9. Changing file organization without changing the conceptual schema demonstrates:
A. Logical data independence
B. Physical data independence
C. Referential integrity
D. Normalization
Answer: B
Q10. Changing the conceptual schema without requiring changes to external views demonstrates:
A. Physical data independence
B. Logical data independence
C. Physical security
D. Data redundancy
Answer: B
Q11. Which type of data independence is generally concerned with changes to storage structures?
A. Logical
B. Physical
C. External
D. Conceptual
Answer: B
Q12. Which type is concerned with changes to the logical structure of the database?
A. Physical data independence
B. Logical data independence
C. Storage independence
D. View independence
Answer: B
Q13. A user's view of the database belongs to which level?
A. External
B. Conceptual
C. Internal
D. Physical
Answer: A
Q14. A table such as STUDENT(StudentID, Name, GPA) primarily represents the:
A. External level
B. Conceptual level
C. Internal level
D. Hardware level
Answer: B
Q15. Disk blocks, indexes, and file organizations are primarily associated with:
A. External schema
B. Conceptual schema
C. Internal schema
D. User schema
Answer: C
Q16. Which change is most clearly a physical-level change?
A. Adding a new table
B. Renaming a column
C. Creating a B+ tree index
D. Adding an attribute to a relation
Answer: C
Q17. Which change is most clearly a logical-level change?
A. Changing from HDD to SSD
B. Creating a B+ tree index
C. Adding a column to a relation
D. Changing the page size
Answer: C
Q18. Data independence primarily reduces the dependency between:
A. Users and passwords
B. Different levels of database abstraction
C. CPU and memory
D. Tables and SQL keywords
Answer: B
Q19. Which mapping connects the external schema to the conceptual schema?
A. External-conceptual mapping
B. Conceptual-internal mapping
C. Physical-external mapping
D. User-storage mapping
Answer: A
Q20. Which mapping connects the conceptual schema to the internal schema?
A. External mapping
B. Conceptual-internal mapping
C. User mapping
D. View mapping
Answer: B
Q21. A DBMS changes a heap file to a B+ tree-based storage structure. The application programs remain unchanged. This demonstrates:
A. Logical data independence
B. Physical data independence
C. Logical dependency
D. Referential integrity
Answer: B
Q22. A database administrator adds an index to improve query performance. Which schema is primarily affected?
A. External
B. Conceptual
C. Internal
D. External and conceptual only
Answer: C
Q23. A new attribute Email is added to the STUDENT relation, but existing user views do not use it. This can demonstrate:
A. Physical data independence
B. Logical data independence
C. No data independence
D. Transaction independence

Q24. A table column Course is renamed to Program, while an existing user view continues to display Course. What allows this?
A. Physical mapping
B. External-conceptual mapping
C. Conceptual-internal mapping only

Answer: B
Q25. Which change would normally NOT require changes to application programs if physical data independence is maintained?
A. Changing a file organization
B. Removing a required logical attribute
C. Changing the logical relationship between tables
D. Changing a user's view
Answer: A
Q26. Which change would normally be associated with logical data independence?
A. Changing disk storage
B. Adding an index
C. Changing the conceptual schema while preserving external views
D. Changing page size
Answer: C
Q27. Which of the following is an example of a physical schema change?
A. Add Phone to STUDENT
B. Rename STUDENT to LEARNER

Q28. Which is an example of a logical schema change?
A. Change disk block size
B. Create a B+ tree index
C. Add a new attribute to a relation
D. Move database files to another disk
Answer: C
Q29. Why is physical data independence generally easier to achieve?
A. Physical changes usually do not alter the logical meaning of data
B. Physical changes always require application modifications

Q41. Consider:
External: StudentID, Name, GPA
Logical: StudentID, Name, GPA, Email
Physical: B+ Tree storage

A. External schema changes
B. Logical schema changes
C. Physical schema changes

Q42. Consider an external view:
StudentView(StudentID, Name, GPA)
The conceptual schema changes from:
STUDENT(StudentID, Name, GPA)
to:
STUDENT(StudentID, FirstName, LastName, GPA)
The DBMS maintains the old view by constructing Name from FirstName and LastName.
What does this demonstrate?
A. Physical data independence
B. Logical data independence
C. Physical storage optimization
D. Transaction isolation
Answer: B

Q43. A database changes its physical storage from:
Heap → Sequential → B+ Tree
while applications continue using the same relations and views.
How many schema levels are directly affected by these storage changes?
A. One
B. Two
C. Three
D. None
Answer: A
Explanation: The physical/internal level changes while the conceptual and external levels can remain unchanged.

Q45. Consider:
